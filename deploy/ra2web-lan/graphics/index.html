画面与鼠标设置

Windows 双显卡电脑上，Edge 使用的显卡会影响游戏画面和鼠标跟手程度。游戏已请求高性能显卡；系统设置决定最终分配。

1. 查看游戏正在用哪块显卡

返回游戏，点击右下角的「画面 / 鼠标」，查看实际显卡、画面帧率和较慢帧间隔。比较调整前后的读数时，使用相同地图、相近单位数量，并保持游戏标签页在前台。

显卡名称来自当前游戏使用的 WebGL 上下文；浏览器可能限制名称显示。帧间隔用于观察绘制是否平稳，不能直接测量鼠标端到端延迟。

2. Windows 为 Edge 选择高性能显卡

  1. 打开 Windows「设置 → 系统 → 显示 → 图形」。打开图形设置
  2. 添加桌面应用，选择实际安装的 msedge.exe。常见位置是 C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe，也可能位于 C:\Program Files\Microsoft\Edge\Application\msedge.exe。
  3. 选择 Edge →「选项」→「高性能」，核对对应显卡名称，例如 RTX 3050，然后保存。
  4. 保存其他标签页的工作，结束当前对局后完全退出 Edge，再重新打开游戏。若后台进程仍在运行，可在 Edge 的 edge://restart 页面重启；请先保存未完成的内容。

该设置针对这台电脑上当前用户的 Edge，对局域网和公网两个网址同时生效。其他电脑需要各自设置。

只有一块显卡、两种模式显示同一块显卡，或瓶颈来自 CPU / 联机时，切换显卡不一定改善体验。

高级：使用可撤销的 PowerShell 脚本

脚本默认只查看状态。应用时自动查找 Edge，备份原值，仅调整当前用户的 Edge 显卡偏好；恢复时使用这份备份。脚本不结束浏览器、不修改其他应用，也不自动运行。

下载显卡设置脚本

在下载目录打开 PowerShell，先查看状态：

.\winlife-edge-gpu.ps1 -Action Status

应用高性能偏好，之后手动重启 Edge：

.\winlife-edge-gpu.ps1 -Action Apply

恢复脚本应用前的值：

.\winlife-edge-gpu.ps1 -Action Restore

执行策略阻止脚本时，使用上面的 Windows 图形设置步骤即可。此脚本需在 Windows 上运行；网页本身没有修改注册表的权限。已有其他工具设置过高性能的电脑无需重复应用。

3. 检查 Edge 图形加速

在地址栏打开 edge://settings/system，确认「使用图形加速（如可用）」已开启。再打开 edge://gpu，检查 Graphics Feature Status 中 WebGL 的加速状态，以及实际渲染器。

若显示 SwiftShader、软件渲染或 Microsoft Basic Render Driver，检查显卡驱动和图形加速设置。调整完成后重新启动 Edge。

4. 分清画面慢和联机慢

指针或滚屏拖动不跟手

查看实际显卡与帧率；尝试降低游戏分辨率，并关闭占用显卡较多的程序后比较。

点击后单位反应慢、全体一起停顿

查看房间内各玩家的往返延迟、抖动和等指令提示，继续检查网络与同步情况。

5. 浏览器手势干扰游戏操作

游戏页面已限制浏览器捏合缩放、画布滚动、下拉刷新及支持的侧滑前进/后退。普通滚轮继续交给游戏处理，菜单列表和输入框保留正常操作。

如果按住右键拖动时出现轨迹、后退或刷新：在 Edge 设置中搜索「鼠标手势」，关闭该功能。它由浏览器处理，网页无法替你关闭；每台电脑需要分别设置。

操作系统的三指、四指切换和部分边缘手势，也需要在系统或浏览器设置中调整。网页保留正常的返回、刷新按钮及快捷键。
